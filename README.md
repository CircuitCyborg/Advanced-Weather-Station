# Advanced-Weather-Station

Local Weather Station that incorporates weather from the user location and displays everything on a local desk base station.

Possible Future Features -

Incorporating forecast from a weather service onto the Base Station.
Communication between modules through the LAN
Limited Smart Home Automations through Base Station

To view the Weather Station in 3D Open this link: https://cad.onshape.com/documents/2aa1986e22143bf0c5bf430b/w/d39aab6bbb374c6101d395f4/e/43a2d6a15468c7d35dd3c23b?renderMode=0&uiState=6ae6a9e5bb2c688de4aefb5d

The purpose of designing this project was to have the most accurate weather information for my exact location. Weather apps are cool, but they are just a reading of where the weather module is for that company. My weather station gives a reading of what my exact location's weather is instead so I will have the most accurate weather data for my location.

For the few who want to build this themselves, there will be a bit of hand wiring that will have to happen. For this wiring, you will need 10 conductors for the direction sensor, 3 conductors for the temp/humidity sensor, 3 for the wind speed sensor, and 3 for the precipitation module. If you purchase enough, you should be able to use the extra ethercon cable for those conductors. When wiring, take your time, be patient with yourself, and have fun!
